## 1. الهدف والسياق (Description & Context)
بناء واجهات المصادقة الحديثة والآمنة (تسجيل دخول المحامي وإنشاء حساب جديد) باستخدام shadcn/ui وتصميم فاخر يدعم اللغة العربية مع ربطها بـ Supabase Authentication والتحقق من المدخلات عبر Zod.

## 2. الملفات والمكونات المستهدفة (Target Components & Files)
- `src/app/(auth)/login/page.tsx`
- `src/app/(auth)/register/page.tsx`
- `src/components/auth/AuthForm.tsx`

## 3. معايير القبول الإلزامية (Acceptance Criteria - AC)
- [ ] نموذج تسجيل الدخول بالبريد الإلكتروني وكلمة المرور.
- [ ] نموذج إنشاء حساب جديد يتضمن اسم المحامي ورقم القيد بنقابة المحامين.
- [ ] التحقق من صحة المدخلات وعرض رسائل خطأ واضحة باللغة العربية.
- [ ] التوجيه التلقائي إلى الـ Dashboard فور نجاح المصادقة.
- [ ] دعم اتجاه RTL والتصميم المتجاوب للموبايل والديسكتوب.

## 4. متطلبات التفاعل والحالات / القيود (UX / Technical Invariants)
- **Loading State:** تعطيل الأزرار وعرض مؤشر تحميل (Spinner) عند إرسال الطلب.
- **Error State:** إظهار Toast notification عند فشل تسجيل الدخول أو وجود خطأ من السيرفر.

## 5. الاختبارات والفحوصات المطلوبة (Required Quality Checks)
- [ ] نجاح أمر البناء التشغيلي (`npm run build`).
- [ ] خلو الصفحة من أخطاء الـ Console.

## 6. تعريف الإنجاز (Definition of Done - DoD)
- [ ] تم تجربة التسجيل وتسجيل الدخول بنجاح.
- [ ] الكود نظيف ومعتمد بنسبة 100%.
