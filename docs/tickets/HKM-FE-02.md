## 1. الهدف والسياق (Description & Context)
بناء واجهات المصادقة الحديثة والآمنة (تسجيل الدخول وإنشاء حساب جديد) باستخدام shadcn/ui وتصميم فاخر يدعم اللغة العربية مع ربطها بـ Supabase Authentication والتحقق من المدخلات عبر Zod.
تتضمن شاشة التسجيل خيار التبديل التفاعلي بين:
1. **تسجيل كمحامٍ (Lawyer):** يطلب الاسم، البريد، كلمة المرور، رقم الهاتف، ورقم القيد بنقابة المحامين.
2. **تسجيل كعميل / طالب استشارة (Client):** يطلب الاسم، البريد، كلمة المرور، ورقم الهاتف.

## 3. معايير القبول الإلزامية (Acceptance Criteria - AC)
- [ ] نموذج تسجيل الدخول بالبريد الإلكتروني وكلمة المرور مع التوجيه حسب الدور.
- [ ] تبويب تفاعلي لاختيار الدور (محامٍ 👨‍⚖️ / عميل 👤) في شاشة إنشاء الحساب.
- [ ] إرسال الـ `role` والبيانات الإضافية في الـ `options.data` مع دالة `signUp`.
- [ ] التحقق من صحة المدخلات (Zod validation) وعرض رسائل خطأ واضحة باللغة العربية.
- [ ] التوجيه التلقائي للمحامي إلى لوحة التحكم `/dashboard`، والعميل إلى صفحته المخصصة.
- [ ] دعم اتجاه RTL والتصميم المتجاوب للموبايل والديسكتوب.

## 4. متطلبات التفاعل والحالات / القيود (UX / Technical Invariants)
- **Loading State:** تعطيل الأزرار وعرض مؤشر تحميل (Spinner) عند إرسال الطلب.
- **Error State:** إظهار Toast notification عند فشل تسجيل الدخول أو وجود خطأ من السيرفر.
