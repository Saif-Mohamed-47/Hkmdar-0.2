1. ملخص المشروع ومبررات الاختيار

لماذا يمثل "حكمدار" مشروع تخرج استثنائي ورائد؟

💡 فكرة المشروع الجوهرية:

مشروع حِكِمْدار هو أول منصة حوسبة قانونية ذكية متخصصة في القانون المصري. يهدف المشروع إلى رقمنة وأتمتة منظومة العمل القضائي والاستشارات بين الموكل ومكاتب المحاماة، وتوظيف أحدث تقنيات نماذج اللغات الكبيرة (LLMs) لتقديم تكييف قانوني دقيق، بحث فوري في 20 تخصصاً تشريعياً، وتوليد صحف الدعاوى والمذكرات بصيغ تنفيذية جاهزة.

❌ المشكلات الواقعية في السوق (Problem Statement):

• صعوبة وصول المواطن لاستشارة قانونية أولية موثوقة ومبنية على نصوص مواد القانون.
• استنزاف وقت المحامين في صياغة العرائض الروتينية وحساب الرسوم والمستحقات يدوياً.
• تشتت سوابق محكمة النقض والمواد التشريعية بين المراجع الورقية وصعوبة البحث السريع.
• غياب منصة موحدة لإدارة حافظة مستندات القضايا (PDF/Word/Excel) وتتبع الجلسات.

✅ الحلول المبتكرة في حكمدار (Our Solution):

✓ مستشار ذكاء اصطناعي (Gemini 1.5 Pro) يستوعب العامية المصرية ويستخرج ملف قضية رسمي.
✓ محرك صياغة مذكرات وصحف دعاوى مؤصلة بالمواد ونصوص النقض بضغطة زر.
✓ قاعدة بيانات تشريعية تضم 20 تخصصاً قانونياً ومحافظات مصر الـ 27 مع بحث صوتي ونصي متسامح.
✓ نظام حافظة مستندات يدعم PDF, Word, Excel مع تخزين سحابي آمن وتتبع الجلسات.

🎯 الأهداف الأكاديمية والتطبيقية للمشروع:

1. تطبيق الذكاء الاصطناعي بناء Prompt Engineering و Retrieval Engine متقدم ومتوافق مع القوانين المحلية.
2. بنية برمجية حديثة تطبيق معايير Full-Stack الحديثة عبر Next.js 15 و Supabase و Tailwind CSS.
3. منتج جاهز للسوق تصميم تجربة مستخدم (UX/UI) فائقة الفخامة تخدم الموكلين ونقابة المحامين فعلياً.

📊 مخطط تدفق العمليات الذكية (AI Processing Flow):

1. إدخال الموكل / المحامي ➔ استيعاب الواقعة بالعامية أو الفصحى عبر واجهة المحادثة التفاعلية.
2. طبقة التطهير اللغوي ➔ تطبيع الحروف العربية (Normalize Alef/Taa) واستخراج المصطلحات الجنائية والمدنية.
3. محرك RAG السيادي ➔ مطابقة الواقعة مع مواد القوانين المصرية (المدني، العقوبات، العمل، الجرائم الإلكترونية، الشركات).
4. التوليد اللحظي عبر Gemini Pro ➔ صياغة التكييف القانوني، خطة الدفاع، واستخراج ملف القضية التنفيذي (Case Dossier).
5. إسناد القضية وتتبعها ➔ إرسال الملف لمحامي النقض المختص وتخزين المستندات (PDF/Excel) في قاعدة البيانات.

🔒 معايير الأمان والخصوصية القضائية (Security & Privacy):

• عزل البيانات (Row Level Security): صلاحيات صارمة تمنع وصول أي مستخدم لملفات قضايا ومستندات المحامين الآخرين.
• حماية الأسرار المهنية: تشفير كامل لكافة محادثات الاستشارة ومذكرات الدفاع المرفوعة.
• اعتماد هوية المحامين: ربط حسابات المحامين بأرقام القيد بنقابة المحامين المصرية (Bar Number).

🚀 موقف الإنجاز الحالي (Current Status):

تم بناء النواة البرمجية والمنظومة التشغيلية الكاملة (Core Architecture & UI Engine) واختبار الذكاء الاصطناعي مع نماذج Gemini 1.5 Pro وتجهيز قاعدة البيانات التشريعية بالكامل، والمشروع جاهز حالياً للعرض والمناقشة الأولية للاعتماد.

المرحلة المهام والمخرجات الفنية التقنيات المستخدمة نسبة الإنجاز
المرحلة 1: التحليل والتصميم دراسة احتياجات السوق القانوني، هندسة متطلبات النظام، وتصميم هوية "حكمدار" وواجهات الـ UI/UX. Figma · Design Tokens · Dark Luxe 100% (مكتملة)
المرحلة 2: الواجهات والـ Frontend بناء بوابتي الموكل والمحامي، محرك البحث الذكي في 27 محافظة و 20 تخصصاً، والتطبيع اللغوي للعامية. Next.js 15 · Tailwind · Lucide 100% (مكتملة)
المرحلة 3: دمج الذكاء الاصطناعي تكامل Gemini 1.5 Pro Streaming API، بناء RAG للمواد المصرية، ومولد المذكرات القضائية الآلي. Google AI SDK · Prompt Tuning 100% (مكتملة)
المرحلة 4: قواعد البيانات والملفات إدارة القضايا، مزامنة الجلسات، ونظام حافظة المستندات والمرفقات (PDF / Word / Excel). Supabase PostgreSQL · Storage 100% (مكتملة)
المرحلة 5: التوثيق والاختبارات إعداد وثيقة التخرج، اختبارات الأداء وسرعة الاستجابة، وتجهيز سيناريو العرض النهائي (Demo Day). Playwright · CI/CD · Documentation قيد التسليم والاعتماد

🌟 الإضافات المستقبلية المقترحة لمرحلة المناقشة (Future Roadmap):
